# Temu-Inspired UI/UX Design Guide (for a Laravel + Vue.js SaaS E-commerce Platform)

## Design Principles

-   Mobile-first, responsive.
-   Bright, conversion-focused interface.
-   Fast checkout.
-   Clear product hierarchy.
-   Consistent spacing (8px grid).

## Color Palette

  Role         Color
  ------------ ---------
  Primary      #FF6A00
  Secondary    #FF8F1F
  Success      #22C55E
  Error        #EF4444
  Background   #F8F8F8
  Text         #1F2937

## Typography

-   Font: Inter
-   H1: 36px Bold
-   H2: 28px Semibold
-   Body: 16px Regular
-   Caption: 13px

## Layout

-   Sticky header with search.
-   Left category navigation (desktop).
-   Bottom navigation (mobile).
-   12-column desktop grid.
